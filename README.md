# Tab Organizer

## 📌 Overview
Tab Organizer is a Chrome extension that helps you manage your tabs efficiently by grouping them based on domain and allowing you to save and restore tab sessions.

## 🚀 Installation Guide

### Step 1: Download the Extension
Go to the GitHub repository and download [HERE](https://github.com/ossd-s25/Tab-Organizer).

### Step 2: Load the Extension into Chrome
1. Open **Google Chrome**.
2. Navigate to **chrome://extensions/**.
3. Enable **Developer mode** (toggle in the top-right corner).
4. Click **Load unpacked**.
5. Select the extracted folder containing `manifest.json`.
6. The extension should now be installed and visible in your Chrome toolbar.

## 🛠 How to Use

### Group Tabs by Domain**
1. Click the **Tab Organizer** extension icon.
2. Click the **"Group Tabs"** button.
3. Your open tabs will be grouped by domain.

### **Save Current Session**
1. Click the **Tab Organizer** extension icon.
2. Click **"Save Session"**.
3. Your current open tabs will be saved for later use.

### **Restore Saved Session**
1. Click the **Tab Organizer** extension icon.
2. Click **"Restore Session"**.
3. Your previously saved session will be restored as new tabs.

## 📝 Notes
- You must **manually reload** the extension if you make changes to its files.
- Chrome **does not allow automatic updates** for unpacked extensions, so you need to reload it manually when updating from GitHub.
