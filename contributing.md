# Contributing to Tab Organizer

Thank you for your interest in contributing to Tab Organizer 🚀 We welcome all contributions, whether it's bug fixes, new features, or documentation improvements.

## 📌 How to Contribute

1. Fork the Repository – Click the "Fork" button at the top right of the GitHub page.
2. Clone Your Fork – Run the following command in your terminal:
   ```sh
   git clone https://github.com/yourusername/tab-organizer.git
   ```
3. Create a New Branch – Use the following command:
   ```sh
   git checkout -b feature-name
   ```
4. Make Your Changes – Edit the code, fix bugs, or add new features.
5. Commit Your Changes –
   ```sh
   git commit -m "Added a new feature"
   ```
6. Push Your Changes –
   ```sh
   git push origin feature-name
   ```
7. Submit a Pull Request (PR) – Go to the GitHub repo and create a PR.

## 🛠 Development Guidelines
- Follow the existing code style and naming conventions
- Ensure your changes do not introduce new errors.
- Test your modifications before submitting a PR.
